Features

Everything You Need for AI-Powered Web Development

💬

Natural Language Driven

Describe your site in Chinese or English. The agent reads scaffold docs, studies templates, and generates optimized code.

🤖

Subagent Delegation

Spawns up to 3 research subagents for documentation reading and pattern searching — freeing the main agent for design decisions.

⚡

Streaming Generation

Every tool call, reasoning chain, and code output streams in real-time. The entire process is transparent.

📦

Self-Contained Builds

All HTML, CSS, and JavaScript inlined into a single file. Zero external dependencies. Instant preview.

♿

Accessibility Built-In

Semantic HTML, ARIA labels, keyboard navigation, color contrast, skip-to-content link — all auto-enforced.

🔄

Iterative Refinement

Multi-turn conversations refine every aspect — layout, colors, typography, interactivity — without starting over.

Get Started

Quick Start

Requires Node.js 18+ and a DeepSeek API Key.

Terminal 
# Clone the repository
git clone https://github.com/1998x-stack/ai-web.git
cd ai-web

# Install dependencies
npm install

# Start the development server
npm run dev
# Open http://localhost:3000
# Configure your API key in Settings → start creating sites
